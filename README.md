# مذكّر الأذكار — تطبيق أندرويد

التليفون بينطق ذكر بصوت عالي كل فترة بتحددها، حتى والشاشة مقفولة.

## البناء
أي push على GitHub بيشغّل GitHub Actions اللي بيبني `DhikrReminder.apk`
وبينزله في صفحة Releases.

## على التليفون
1. نزّل `DhikrReminder.apk` من Releases وسطّبه (وافق على «التثبيت من مصادر غير معروفة»).
2. وافق على إذن الإشعارات.
3. اضغط «السماح بالعمل في الخلفية» واختار «غير مقيّد» / «Unrestricted» للتطبيق.
4. اضغط «جرّب الصوت» — لو ما نطقش، نزّل اللغة العربية من إعدادات تحويل النص إلى كلام.
5. اختار المدة واضغط «ابدأ التذكير» واقفل الشاشة.
